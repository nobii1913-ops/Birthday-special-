# Gungun's Birthday Surprise Website 💖

A mobile-friendly, single-file birthday website with:
- Interactive surprise reveal
- Animated cake and candle wish
- Gift button and personalized Hinglish birthday letter
- Final surprise and confetti
- Synthesized instrumental Happy Birthday melody generated in-browser (no external audio file needed)

## Preview locally
Open `index.html` in a browser. Tap **Play music** to start the original melody; mobile browsers require a tap before playing audio. If you still hear nothing, turn up media volume and try opening the published page directly in Chrome.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `gungun-birthday`).
2. Upload `index.html` (and this README if you like) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish, then open the URL shown in the Pages settings.

## Personalize
Open `index.html` and edit the letter text, especially the sign-off (`Tera online dost`). You can also change the colors in the `:root` CSS section.
